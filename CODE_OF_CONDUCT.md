# Code of Conduct

## TL;DR

Be respectful. We're musicians and engineers. Treat each other like you'd treat a co-producer in a session.

## Standards

- **Constructive feedback only.** "This skill could be better because X" is welcome. "This is bad" is not.
- **Credit prior work.** If your skill builds on someone else's technique, repo, or PR, credit it.
- **No music-snob gatekeeping.** Genres are not better or worse. Don't tell someone their lo-fi is "not real music."
- **Inclusive language.** Use the language a beginner producer would use; don't gatekeep with jargon.
- **No spam.** Don't post promotional content disguised as issues or PRs.

## Enforcement

Unacceptable behavior reported to **conduct@glincker.com** is reviewed within 7 days. Outcomes range from warning to permanent ban from the project.

We use the [Contributor Covenant](https://www.contributor-covenant.org/) as our long-form reference for edge cases.
